Instruction
Configure project settings in .env file

```
cp .env.example .env
```

```
composer install
```

```
php artisan key:generate
```

```
npm install && npm run build
```

Set up database and run migrations

```
php artisan migrate
```

```
php artisan optimize:clear
```

**Run the development server**

```
php artisan serve
```

```
npm run dev
```
